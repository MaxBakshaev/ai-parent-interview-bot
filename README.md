# ИИ-бот для глубинных интервью родителей (Telegram + Claude + n8n)

Telegram-бот на базе **n8n** и **Claude API (Anthropic)**, который проводит структурированное глубинное интервью с родителями школьников: собирает обратную связь о текущей школе (еда, образование, безопасность, буллинг, форс-мажоры, цена) и тестирует реакцию на гипотезы новых ИИ-продуктов для школ. Результаты по 58 полям автоматически сохраняются в Google Sheets, история диалога хранится в MongoDB.

Ключевая инженерная идея проекта — переход от встроенного узла `AI Agent` к **ручной сборке агентного цикла** с явным **prompt caching** Anthropic, что снизило стоимость одного полного интервью с **$1–2 до $0.1–0.2** (см. раздел [Стоимость](#-стоимость)).

## 📐 Архитектура

Бот состоит из нескольких n8n-воркфлоу:

- **`ai-bot-interview-v2-optimized.json`** — точка входа: принимает сообщения из Telegram, подтягивает историю диалога из MongoDB, вызывает движок и отправляет ответ.
- **`claude-agent-turn.json`** — «движок»: собирает запрос к Anthropic API (с кэшированием), обрабатывает вызовы инструментов (`save_interview_results`, `schedule_reminder`) и рекурсивно вызывает сам себя, пока не получит финальный текстовый ответ.
- **`save-interview-results.json`** — записывает/обновляет строку результатов интервью в Google Sheets по `chat_id`.
- **`schedule-reminder.json`** / **`background-reminder.json`** — откладывают продолжение разговора на N минут, если родитель просит перенести разговор.
- **`ai-bot-interview-v1-legacy.json`** — исходная версия на встроенном узле `AI Agent`, сохранена для сравнения (это версия «до» оптимизации, без кэша).

Подробный пошаговый разбор каждого узла и полный путь одного сообщения — в [`docs/architecture.md`](docs/architecture.md).

```
Telegram → ai-bot-interview-v2 → claude-agent-turn ⇄ Anthropic API
                │                        │
           MongoDB (память)      Google Sheets (результаты)
```

## 🧰 Технологии

| Компонент | Назначение |
|---|---|
| [n8n](https://n8n.io/) | оркестрация воркфлоу (self-hosted) |
| Telegram Bot API | интерфейс общения с родителями |
| Anthropic Claude API | модель `claude-haiku-4-5`, диалог + вызов инструментов |
| MongoDB | хранение истории переписки по `chat_id` |
| Google Sheets API | хранение результатов интервью (58 полей на респондента) |

## 💰 Стоимость

Стоимость считалась на реальных диалогах (модель `claude-haiku-4-5`, полное интервью из ~11 шагов сценария).

| Версия | Стоимость одного полного интервью | Почему |
|---|---|---|
| **До** (`ai-bot-interview-v1-legacy.json`, встроенный `AI Agent`) | **~$1–2** | системный промпт, описание инструментов и вся история переписки пересчитываются моделью заново на каждом шаге диалога |
| **После** (`ai-bot-interview-v2-optimized.json` + `claude-agent-turn.json`, ручная сборка + `cache_control`) | **~$0.1–0.2** | статичный системный промпт, описания инструментов и накопленная история помечены как `cache_control: ephemeral` — Anthropic переиспользует кэш вместо повторной оплаты полной стоимости токенов |

Экономия — **на порядок** (~90%) за счёт того, что почти весь контекст (промпт, инструменты, старые сообщения) не меняется от шага к шагу и попадает в кэш, а полную цену модель берёт только за новый вход и новый выход.

## 🚀 Как развернуть

1. Поднимите свой **n8n** (self-hosted или n8n Cloud).
2. Создайте credentials в n8n:
   - **Telegram API** — токен вашего бота от [@BotFather](https://t.me/BotFather);
   - **Anthropic API** — ключ с [console.anthropic.com](https://console.anthropic.com/);
   - **MongoDB** — строка подключения (использует базу `n8n_bot_memory`, коллекцию `claude_agent_history`);
   - **Google Sheets OAuth2** — доступ к вашей Google-таблице.
3. Импортируйте воркфлоу в n8n (`Import from File`). Привязки credentials из файлов удалены намеренно, поэтому после импорта каждый узел Telegram / Anthropic / MongoDB / Google Sheets будет показан как «не настроен» — назначьте в нём соответствующий credential вручную.
4. В узлах `Get row(s) in sheet` / `Append or update row in sheet` (файл `save-interview-results.json`) замените плейсхолдер `YOUR_GOOGLE_SHEET_ID_HERE` на ID вашей собственной Google-таблицы. Структуру колонок можно взять из `data/interview_results_template.xlsx`.
5. При желании отредактируйте текст-заглушку `Имя Фамилия` в приветственном сообщении и в системном промпте (`claude-agent-turn.json` / `ai-bot-interview-v1-legacy.json`) на то, как должен представляться бот.
6. Активируйте все воркфлоу.
